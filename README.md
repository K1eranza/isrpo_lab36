## Описание проекта

TaskBoard — это интерактивная доска задач, реализованная по принципу Fullstack-приложения. Проект позволяет пользователю:

- Просматривать список всех задач с сортировкой (невыполненные — сверху, новые — выше внутри группы)
- Добавлять новые задачи с заголовком и описанием
- Отмечать задачи как выполненные / невыполненные через чекбокс
- Редактировать заголовок и описание задачи прямо в интерфейсе
- Удалять задачи с подтверждением
- Фильтровать задачи по статусу: все / в работе / выполненные
- Автоматически подсчитывать количество выполненных задач

**Технологический стек:**
- **Backend:** ASP.NET Core Web API, Entity Framework Core, SQLite
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **Инструменты:** Swagger (OpenAPI), CORS, Git

## Инструкция по запуску

### 1. Запуск backend-сервера

```bash
cd TaskBoardApi
dotnet restore
dotnet run
```

### После запуска сервер будет доступен по адресу(в моем случае):

```
API: http://localhost:5206/api/tasks
Swagger UI: http://localhost:5206/swagger
```

## Главные выводы

1. **Fullstack-цикл** — научились связывать ASP.NET Core backend с фронтендом на чистом JS через Fetch API для всех CRUD-операций.

2. **Entity Framework Core** — освоили создание модели, контекста, автоматическую миграцию при запуске и заполнение БД начальными данными через `HasData()`.

3. **Асинхронность** — применяли `async/await` на бэкенде и фронтенде для неблокирующей работы с БД и сетью.

4. **Управление состоянием** — реализовали локальный массив `allTasks` и фильтрацию без лишних запросов к серверу, а также динамический подсчёт выполненных задач.

5. **Безопасность** — добавили валидацию модели, обработку ошибок, два режима карточки задачи.
